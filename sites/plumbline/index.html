The platform

One network for data, messages and proof.

Plumbline gives onchain products a shared foundation: values that independent sources sign, messages that respect limits, and reserves anyone can check. Start with one service and add the rest on the same security.

  1. 01FeedsMarket and reference data signed by independent sources, pushed on deviation and on a heartbeat.
  2. 02RelayMessages and value transfers between networks, inside rate limits you set for each lane.
  3. 03AttestProof of reserves from custodians, bank accounts and wallets, published on a schedule.
  4. 04ComputeOffchain jobs with a signed, replayable result, for logic too heavy to run onchain.

Developers

Ship in an afternoon. Audit it forever.

Read a signed value in a few lines, test against a simulator that replays real market days, and deploy to any of 52 networks with the same interface.

  • SDKs for Solidity, TypeScript, Rust and Go
  • Free testnet feeds on every supported network
  • A local simulator that replays historic market days

contracts/CollateralCheck.sol

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import {IPlumbFeed} from "@plumbline/contracts/IPlumbFeed.sol";

contract CollateralCheck {
    IPlumbFeed public immutable feed;
    uint256 public constant MAX_AGE = 1 hours;

    constructor(address feedAddress) {
        feed = IPlumbFeed(feedAddress);
    }

    function latestValue() external view returns (int256) {
        (int256 value, uint64 updatedAt, ) = feed.latestRound();
        require(block.timestamp - updatedAt <= MAX_AGE, "stale");
        return value;
    }
}

scripts/read-feed.ts

import { createClient } from "@plumbline/sdk";

const plumb = createClient({ network: "testnet" });

// Read the latest round, then check its signatures
// before you use the value anywhere.
const round = await plumb.feeds.latest("EUR/USD");
await plumb.verify(round);

console.log(round.value, round.sources.length, round.updatedAt);

Network

Every feed and every heartbeat, in the open.

Each value shows its sources, its last round and how far it moved. You set your own deviation and freshness limits, and the monitor flags a feed before it crosses them.

Heartbeat
The longest a feed may go without a new round.
Deviation
The move that forces a new round early.

Quickstart

  1. Install the SDK

    npm install @plumbline/sdk

  2. Point it at a testnet

    Testnet feeds are free and mirror mainnet sources on a delay.

    PLUMB_NETWORK=testnet

  3. Read and verify a round

    const round = await plumb.feeds.latest("EUR/USD");
await plumb.verify(round);
